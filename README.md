# CIS183_FinalProject

The user starts off at the sign in page, or MainActivity, where they are given the option to sign in or sign up. Both signing in and signing up ensure that there are no blank spaces in the textboxes and when signing in, username must exist. When signing up, username has to be unique (not already existing). After signing up or in, the user enters the home page where they can choose to play intermediate difficulty or easy difficulty, view their profile, view the leaderboard, or sign out. Signing out of course takes them back to the sign in page.

If user chooses to play easy mode, the bot will not do chain captures and will instead only check to see if they can first capture, and if not move. This is done on a randomly selected piece, making the match easier on the player. Previous turns are logged and visible to the player, so is a timer that shows how many seconds have passed. There will be a text alert for when it is the players turn, and also an alert for when the player can do a chain capture. If user wishes to back out of the match, they simply have to press the arrow in the top left corner. If the bot is trapped, match ends and user wins. If there are no bot pieces left, match ends and user wins. If user is trapped, match ends and bot wins. If user has no pieces left, match ends and bot wins. At the end of the match, result (won or lost), turn numbers, and total time spent on match is displayed to the user. If the user wishes to retry, they have to press the retry button and the board will be reset. If not, they will press the quit button and be taken to the home page.

If user chooses to play intermediate mode, mainly everything will be the same UI wise as the easy bot. However, the functionality of the bot is different. Intermediate bot can do chain attacks, and also sorts moves on optimal and least optimal. It chooses to do optimal moves first before considering least optimal. The bot will also push for capturing pieces if available to it, only if it considers it safe though. This bot is smarter than the easy bot, allowing for more of a challenge to the user without being too difficult.

From the home page, if the user clicks on their profile button, their first name, last name, email, total number of points, average time per match, and matches will be displayed. If they won, the matches color will be that of the light pieces in the checkers game. If they lost, it will be that of the dark pieces in the checkers game. When the user clicks on a match in the list, they will be taken to a seperate screen where the result, difficulty total time for the match, and the moves will be displayed. User can the to and from of the user and bot move for each turn. The user can exit out of this page by pressing the back button. If the user wishes to delete their account, they simply press the delete account button and then hit yes on the alert confiming that they truly wish to delete their account. If they didn't mean to press the delete account button, they press the no button in the alert. After deleting their account they will be sent to the sign in page and their account and its data will no longer exist. If the user wishes to update their information, the can press the update button. They will be taken to a page where they can edit their first name, last name, and email. There is error checking in place making sure no textboxes are empty on pressing the update button.

From the home page, if the user clicks on the leaderboard button, they will see a ranking of top score to least top scores in all the users. It is ordered by the total match points a user has. Each cell displays the username and the match points of the user, along with their rank. If the user clicks on one of the cells, they can view the other users profile and click on their matches to see all the moves from the selected match. User cannot update or delete other users account.
